An offline, zero-dependency web app guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI, built for make.fun's **"Build the best GTA 6 trophy guide"** bounty ($250 prize pot). Every trophy carries an original guide with kind, missable flag and note, ordered steps, a platinum-roadmap stage and cited sources (PowerPyx, PSNProfiles, Exophase, community threads).

Features: checklist with localStorage progress, export/import to JSON, filters (all / story / missable / collectibles / activities / online), a spoiler mode that hides story trophies until earned, a six-stage platinum roadmap with missable flags throughout, and a detail panel with description, guide, steps and sources. Plain vanilla JS/CSS, no CDN, no network calls.

## Run it

```sh
# open app/index.html in any browser — fully offline, no build step needed
node main.ts   # optional: rebuild the entry dossier into out/
```
