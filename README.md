# Leonida Ledger

[![Make.fun competition entry](https://make.fun/badges/gta6-trophy-guide-01)](https://make.fun/competitions/gta6-trophy-guide-01)
[![GitHub repository](https://img.shields.io/badge/GitHub-Kendisamar01%2Fgta6--trophy--guide--01-181717?logo=github)](https://github.com/Kendisamar01/gta6-trophy-guide-01)

An offline-first, fan-made GTA VI trophy planner with 64 speculative checklist entries, field notes, filters, rarity estimates, and progress stored on your device. This is a creative planning set, not an official or verified trophy list.

## Run locally

Use Node.js 22 or newer; no packages or network access are needed.

```sh
node main.ts
node serve.ts
```

Open [http://127.0.0.1:8080](http://127.0.0.1:8080). The generated static build is in `out/`. Your checklist stays in this browser; use Export and Import to move it between devices.
