A standalone, offline companion for the 55 PlayStation 5 trophies in Grand Theft Auto VI. Browse requirements and route notes, keep a local completion checklist, hide story details until earned, and follow a six-part platinum roadmap. Progress can be exported to or restored from a JSON file.

## Run it

```sh
node main.ts
```

The command builds the app and dossier in `out/`. To serve the built app locally, run:

```sh
node serve.ts
```
